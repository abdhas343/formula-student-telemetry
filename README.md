🏎️ Formula Student – Live Telemetry Dashboard

A Python-based telemetry dashboard for a simulated electric Formula Student race car.

Dashboard Preview



Features

Real-time-style telemetry visualization

Vehicle speed, battery level and temperature monitoring

Vehicle Dynamics Analysis: acceleration and braking

Interactive Plotly charts

Automatic system diagnostics and temperature warnings

Online demo mode with simulated data

Tech Stack

Python · Streamlit · Pandas · Plotly

How It Works

The simulator generates vehicle telemetry data. The dashboard processes the measurements and visualizes vehicle performance. When deployed online without a CSV file, it automatically switches to simulated demo mode.
